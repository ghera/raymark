# Settings VS Code

## Formattazione automatica

C_Cpp: Formatting -> clangFormat
Editor: Default Formatter -> C/C++ Extension Pack
Clang format config: usare il file `.clang-format` nella root del repository

## Errori relativi a make nella tab Output

NON installare l'estensione Makefile Tools quando si usa task.json per i task di build

## Errori duplicati nella tab Problems

Disabilitare gli errori di Intellisense per non avere dublicati
"C_Cpp.errorSquiggles": "disabled" in settings.json
